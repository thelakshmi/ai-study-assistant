# AI Study Assistant

A beginner-friendly AI study assistant built with Python and the Hugging Face Inference API.  
The current version accepts questions in the terminal and generates AI-powered answers.

## Features

- Interactive terminal-based chat
- Uses Hugging Face Inference Providers
- Keeps API credentials in an environment variable
- Python virtual environment for isolated dependencies
- Git/GitHub version control

## Tech Stack

- Python 3.12
- Hugging Face Inference API
- OpenAI Python SDK
- python-dotenv
- Git & GitHub

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/thelakshmi/ai-study-assistant.git
cd ai-study-assistant
```
